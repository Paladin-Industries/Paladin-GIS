# Security

## Reporting a vulnerability

Email **security@paladinindustries.com**. Please do not open a public issue
for security problems.

## Credentials

This plugin stores the credentials you enter in your QGIS profile settings.
Treat them as you would any API key:

- Do not commit them, paste them into issues, or share a profile directory.
- If a key may have been exposed, contact Paladin for a replacement — keys can
  be rotated without disrupting tactics already synced.

The repository is scanned on release for accidentally committed keys, but that
check is a backstop, not a substitute for care.
